# 팀 합의서 — PM 에이전트 도입

> 합의 기록: (이슈 링크) · 합의일: 2026-  -  · 참여: @팀원1 @팀원2 @팀원3 @팀원4

## 목적
PM 에이전트는 **스탠드업을 빠르게 하기 위한 보조 도구**입니다. 리포트는 팀원 평가나 비교에 쓰지 않습니다.

## 수집하는 것 (팀 GitHub 저장소만, 읽기 전용)
- 커밋: 메시지 첫 줄, 작성자, 시각
- PR·리뷰: 제목, 상태, 리뷰어, 리뷰 시각
- 이슈: 제목, 라벨, 담당자, 상태
- CI: 실행 결과, 실패한 테스트 이름, 실패 로그 마지막 부분

## 수집하지 않는 것
코드 내용, 개인 저장소, Discord 대화, 작업 시간, 이메일 주소(작성자 매칭에만 쓰고 LLM·리포트에는 넣지 않음)

## 약속
1. 리포트는 **팀장 승인 후에만** 팀 채널에 올라갑니다.
2. 커밋 수 같은 숫자로 팀원을 순위 매기지 않습니다.
3. 리포트 내용이 틀리면 ❌ 반응을 남기면 되고, 운영자가 원인을 고칩니다.
4. 특정 항목을 리포트에서 빼고 싶으면 이슈나 DM으로 요청할 수 있고, 운영자가 `config.yaml`에 반영합니다.
5. 평가 기간(평일 5일)에는 ✅/❌ 반응과 하루 한 번 만족도(1~5점)에 참여합니다.
6. 합의 내용을 바꿀 때는 다시 네 명 모두의 동의를 받습니다.
